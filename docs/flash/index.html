Flash GlucoCube

Put the firmware on an ESP32-S3 board from this page. Plug the board in over USB, choose it below, and press Install — nothing to download and nothing to install first.

Which board

Install

This browser cannot talk to a USB serial port. Chrome, Edge or Opera on a desktop can; Safari and Firefox cannot, and nor can a phone. This page has to be served over HTTPS to reach a serial port.

Reading the latest release…

Installing erases the board, firmware and settings alike. A display that is already set up keeps its settings through an ordinary update — Settings → Updates on the device itself — so this page is for a board being set up for the first time, or one being rescued.

Once it is on

The panel lights and shows a QR code. Scan it with a phone and the setup wizard opens: Wi-Fi, where in the world it is so the clock is right, and who it is for. With no network at all the device opens its own GlucoCube-Setup hotspot instead, and the wizard opens by itself once a phone joins it.

Or from a terminal

The same image is attached to every release, and esptool writes it in one command:

esptool.py --chip esp32s3 write_flash 0x0 glucocube-<board>-<version>-factory.bin

GlucoCube is a convenience display, not a medical device. Forecasts are estimates. Don't rely on it for alarms or treatment decisions — use the CGM app's own alerts for that.
